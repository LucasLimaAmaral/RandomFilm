# Cineholic 🎬

O Cineholic é uma API desenvolvida em **Spring Boot** para consulta e gerenciamento de informações sobre filmes, integrada com a API externa do TMDB.

## 🚀 Tecnologias
- Java 17
- Spring Boot 3
- Spring Data JPA
- MySQL
- TMDB API (The Movie Database)

## 🛠️ Funcionalidades
- [x] Integração com API do TMDB.
- [x] Listagem de filmes populares.
- [ ] Autenticação com Spring Security (em desenvolvimento).

## ⚙️ Como rodar o projeto
1. Clone o repositório.
2. Adicione sua `api_bearer` no arquivo `application.properties`.
3. Execute o comando `./mvnw spring-boot:run`.
